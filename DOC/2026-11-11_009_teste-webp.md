# Teste com a imagem otimizada

O WebP de 17.996 bytes foi enviado pelo painel ao bucket privado de homologação. Em transação revertida no Supabase, o arquivo foi confirmado, solicitado para revisão e aprovado. O comprador permaneceu sem acesso ao original. O arquivo ficou no bucket privado sem associação persistente a lote.

A sessão real do Administrador abriu a fila de evidências e recebeu o estado vazio. O teste pelas duas interfaces aguarda uma sessão real de produtor. Não foram criadas contas persistentes.

`npm run verify` passou com tipos, lint, 45 testes e exportação web dos quatro apps.
