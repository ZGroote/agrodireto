# Hub de homologação

O comando `npm run hub` inicia os apps web que estiverem parados e serve o hub local na porta 8082. O hub reúne Agricultor, Cliente, Logística e Administrador, com acesso à entrada e ao mapa de telas de cada app. Os mapas podem ser consultados sem cadastro. Operações protegidas continuam usando a sessão do app.

O hub foi aberto no navegador. Os quatro mapas responderam com HTTP 200. A criação de uma conta de produtor e a configuração de SMTP ficaram para quando forem necessárias ao teste com dados reais.
