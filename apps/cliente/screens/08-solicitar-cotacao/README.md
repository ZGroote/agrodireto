## Objetivo
Pedir cotação de uma oferta.

## Elementos
Voltar, oferta (foto, código, origem), Quantidade (kg), Embalagem, Entrega (data), Enviar cotação.

## Conexões

- **Vai para:** 09 Minhas cotações

## Dados (fase de integração)
Cotações (o produtor responde na 16/17 do Agricultor).

## Pendências e observações
Envio habilita com quantidade e data completa (DD/MM/AAAA).
